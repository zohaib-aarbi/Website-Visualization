Chart.js Tutorial Dashboard
A simple, responsive data visualization dashboard built with HTML5, CSS3, and Chart.js. This project demonstrates how to implement multiple chart types (Line, Bar, and Pie) to visualize financial data like revenue, expenses, and profit.
🚀 Features
Line Chart: Tracks Revenue, Expenses, and Profit trends over a 6-month period.
Bar Chart: Provides a comparative view of monthly Revenue.
Pie Chart: Visualizes the distribution of revenue (Reinvestment, Salary, and Miscellaneous).
Responsive Design: Centered layout with a fixed-width container for clear presentation.
CDN Integration: Uses the Chart.js library via JSDelivr for zero-setup installation.
🛠️ Technologies Used
HTML5: Structure of the dashboard.
CSS3: Styling and layout.
JavaScript (ES6): Logic for data handling and chart initialization.
Chart.js: Simple yet flexible JavaScript charting library.
📋 How to Use
Clone or Copy: Save the code into a file named index.html.
Open in Browser: Double-click the index.html file or use a "Live Server" extension in your IDE (like VS Code).
View Data:
Hover over data points to see tooltips with specific values.
Click legend items to toggle the visibility of specific data series.
